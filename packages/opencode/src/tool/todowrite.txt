Structured task list for tracking multi-step work. Helps the user see progress.

## Rules
- Use when task requires 3+ distinct steps, or user provides multiple tasks.
- MUST NOT use for single/trivial tasks — just do them directly.
- One `in_progress` at a time. Mark complete immediately on finish.

## States
- `pending` — not started
- `in_progress` — actively working (limit: 1)
- `completed` — done
- `cancelled` — no longer needed

## Items
Each todo: `{ id, content, status, priority }` where priority is `high | medium | low`.
