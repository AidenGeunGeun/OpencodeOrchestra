- Matches file paths with glob patterns and returns matching files sorted by modification time.
- Patterns are evaluated relative to `path`; make `path` small first, then make `pattern` precise.
- Always pass a narrow `path` when you know the relevant subdirectory; avoid repo roots, umbrella directories, `.`, `..`, `/`, drive roots like `C:\`, and home/profile directories unless the search is explicitly bounded.
- Narrow with specific `pattern`s such as `src/**/*.ts`, `packages/app/**/*.tsx`, or `**/*.{test,spec}.ts`; avoid catch-all patterns unless the path is already small.
- Default timeout is 30 seconds; pass `timeout` in seconds for intentional wider searches, up to 300 seconds.
- A timeout error means the search was too broad or hit a slow tree; retry with a narrower `path`, more specific glob `pattern`, or larger explicit `timeout`.
- Symlinks are not followed by default; set `followSymlinks: true` only when matching linked trees is intentional.
- Results truncate after the tool limit; if truncated, retry with a narrower `path` or more specific `pattern` instead of treating the list as complete.
- Use `read` when you already know the file path; it is cheaper and avoids unnecessary filesystem scans.
- For open-ended, multi-round codebase exploration, delegate to the Task tool rather than chaining broad `glob`/`grep` calls yourself.
