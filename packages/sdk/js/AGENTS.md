# AGENTS.md — packages/sdk/js

Guide for AI coding agents working inside the `packages/sdk/js` package.

For repo-wide conventions see the root `AGENTS.md`.

## What This Package Is

`packages/sdk/js` is the generated JavaScript/TypeScript SDK for the OpenCode API. It is published as `@opencode-ai/sdk`. Consumers (`packages/app`, `packages/opencode` TUI) import from `@opencode-ai/sdk/v2`.

## Commands

| Task           | Command                      |
| -------------- | ---------------------------- |
| **Typecheck**  | `bun run typecheck` (`tsgo --noEmit`) |
| **Regenerate** | `bunx @hey-api/openapi-ts`   |

## Entry Points

| Import path                  | Source file            | Purpose                                                    |
| ---------------------------- | ---------------------- | ---------------------------------------------------------- |
| `@opencode-ai/sdk/v2`        | `src/v2/index.ts`      | Re-exports all generated types and the client factory      |
| `@opencode-ai/sdk/v2/client` | `src/v2/client.ts`     | `createOpencodeClient` factory                             |
| `@opencode-ai/sdk/v2/server` | `src/v2/server.ts`     | `createOpencodeServer` — spawns the opencode server process |

## SDK Client

`src/v2/client.ts` wraps the generated `OpencodeClient` with two additions:

1. **Disabled fetch timeout** — sets `req.timeout = false` to avoid request timeouts on long-running operations.
2. **`x-opencode-directory` header** — if `config.directory` is supplied, it is URL-encoded and sent as `x-opencode-directory` on every request. This binds all API calls to a specific project directory on the server.

```ts
import { createOpencodeClient } from "@opencode-ai/sdk/v2/client"

const client = createOpencodeClient({
  baseUrl: "http://localhost:4096",
  directory: "/home/user/my-project",  // → x-opencode-directory header
})
```

## SDK Server

`src/v2/server.ts` exports `createOpencodeServer`, which spawns an `opencode serve` subprocess and returns a client connected to it. Useful for programmatic use from Node/Bun scripts.

## Generated Files

Everything under `src/v2/gen/` is generated by `@hey-api/openapi-ts` from the OpenAPI spec produced by `packages/opencode`. **Do not manually edit files in `src/v2/gen/`.**

To regenerate after changing server endpoints:

1. Start the opencode server (or have it emit the spec).
2. Run `bunx @hey-api/openapi-ts` from `packages/sdk/js`.
3. Commit the regenerated files alongside the server changes.

The OpenAPI spec is generated at runtime via `Server.openapi()` in `packages/opencode/src/server/server.ts`. The `script/generate.ts` helper in `packages/opencode` automates the full regen flow.

## Conventions

- Do not edit `src/v2/gen/**` — always regenerate.
- `createOpencodeClient` is the correct factory for application use; do not instantiate `OpencodeClient` directly.
- Pass `directory` to scope requests to a project; omit it only for global endpoints that do not require a project context.
