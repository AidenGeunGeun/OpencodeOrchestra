# Skip Local Server on Desktop — Execution Spec

## Intent

When a remote server is set as the default in the desktop app, skip spawning the local sidecar server on launch. This saves RAM and CPU on resource-constrained machines (e.g., 8GB MacBook) that only need to connect to a remote `oco serve` instance over Tailscale.

## Behavior

- When user clicks "Set as default" on a **remote HTTP server**: automatically set `skipLocalServer: true` in the Tauri store
- When user clicks "Set as default" on the **sidecar** (local server): automatically set `skipLocalServer: false`
- When user clicks "Remove default": set `skipLocalServer: false`
- On launch: if `skipLocalServer` is `true` AND `defaultServerUrl` is set, skip sidecar spawn entirely

### 2. Rust: Server store functions (`packages/desktop/src-tauri/src/server.rs`)

Add getter/setter for `skipLocalServer`:

```rust
#[tauri::command]
#[specta::specta]
pub fn get_skip_local_server(app: AppHandle) -> Result<bool, String> {
    let store = app
        .store(SETTINGS_STORE)
        .map_err(|e| format!("Failed to open settings store: {}", e))?;
    let value = store.get(SKIP_LOCAL_SERVER_KEY);
    Ok(value.and_then(|v| v.as_bool()).unwrap_or(false))
}

#[tauri::command]
#[specta::specta]
pub async fn set_skip_local_server(app: AppHandle, skip: bool) -> Result<(), String> {
    let store = app
        .store(SETTINGS_STORE)
        .map_err(|e| format!("Failed to open settings store: {}", e))?;
    store.set(SKIP_LOCAL_SERVER_KEY, serde_json::Value::Bool(skip));
    store.save().map_err(|e| format!("Failed to save settings: {}", e))?;
    Ok(())
}
```
